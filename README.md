# 공기 레전드 (GONGGI LEGENDS)

우리 반 공기놀이 랭크 리그. 친구와 대결해 이기면 LP를 얻고, 리그 오브 레전드처럼 아이언부터 챌린저까지 티어가 올라갑니다.
**해바라기반 체크리스트(5-3check)와 같은 학생 명단·같은 4자리 비밀번호**를 씁니다.

## 어떻게 쓰나요 (각자 크롬북)

1. 처음 한 번 **로그인**: 내 이름을 고르고 체크리스트와 같은 비밀번호 4자리. 그 크롬북에서는 계속 로그인돼 있어요.
2. **대결**에서 상대를 고르고(추천 · 도전 · 첫 만남) 공기 대결을 해요.
3. 결과 기록은 **한 판에 한 번만** 돼요.
   - 이긴 친구가 **내가 이겼어요** → 진 친구 크롬북에 확인 요청이 떠요 → 진 친구가 **맞아요, 졌어요**를 누르면 기록.
   - 진 친구가 먼저 **내가 졌어요**를 눌러도 바로 기록돼요 (이긴 친구가 보낸 요청은 같이 정리).
   - 방금 기록된 판을 또 "이겼어요"로 올리면 막혀요.
4. 기록되면 두 크롬북 모두에 승리/결과 화면이 떠요.

선생님 메뉴를 열면 한 화면에서 두 선수를 골라 기록하는 **선생님 모드**도 쓸 수 있어요.

- **캐릭터 꾸미기**(본인 비밀번호 필요): 피부 8 · 표정 13 · 머리 모양 7 · 머리 색 9 · 모자 9 · 상의 7 · 상의 색 12 · 하의 색 8 · 등 장식 5.
  일부 아이템은 **티어 보상**이라 그 티어에 올라야 열려요 (시즌 최고 티어 기준이라 내려가도 사라지지 않아요).

  | 티어 | 열리는 아이템 |
  | --- | --- |
  | 브론즈 | 헤드폰, 후드티 |
  | 실버 | 마법사 모자, 정장 |
  | 골드 | 망토 |
  | 플래티넘 | 기사 갑옷, 반짝 눈 |
  | 에메랄드 | 전설의 검 |
  | 다이아몬드 | 날개, 왕족 예복 |
  | 마스터 | 왕관, 각성 눈 |
  | 그랜드마스터 | 마왕의 뿔 |
  | 챌린저 | 천사 고리 |
- 비밀번호가 아직 없는 학생은 처음 쓸 때 만들고, 그 비밀번호는 체크리스트에서도 똑같이 쓰여요.
- **LP 직접 주기·빼기** (선생님 메뉴, 또는 선생님 모드에서 학생 프로필): 여러 명을 골라 칭찬·벌점 LP를 한 번에. 사유와 함께 기록 탭에 남고, 승패·연승에는 영향 없음. 잘못 줬으면 '취소'.
- **선생님 메뉴**: LP 규칙, 결석한 학생 "쉬는 중" 처리, 마지막 대결 취소, 백업, 새 시즌 초기화.

## 다른 선생님 반 (구글 시트, Firebase 없이)

다른 선생님은 **https://kingseoho.github.io/5-3gonggi/?setup** 에 들어가 안내대로 하면 돼요 (10분).

1. 선생님 계정으로 새 구글 시트 → 확장 프로그램 → Apps Script → 안내 화면의 코드(`apps-script/Code.gs`) 붙여넣기
2. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → 웹 앱 URL 복사
3. 안내 화면에 URL 붙여넣기 → 반 이름, 선생님 비밀번호, 학생 명단 입력 → **반 만들기**
4. 선생님 메뉴의 **링크 나눠주기**(주소 `…/5-3gonggi/?sheet=웹앱ID`)를 클래스룸에 올리기

- 명단·경기 기록·학생 비밀번호는 **그 선생님 시트에만** 저장돼요. 시트의 `경기` 탭에서 기록을 직접 보거나 고칠 수도 있어요.
- 학생 비밀번호와 선생님 비밀번호는 시트 밖(앱)으로 내보내지 않고 시트 안에서 확인해요. 선생님 전용 기능(수정·삭제·규칙·쉬는 중·명단·새 시즌)은 시트가 선생님 비밀번호를 확인해야 실행돼요.
- 실시간 알림 대신 5초마다 바뀐 게 있는지 확인해요(화면이 보일 때만).
- 학교 계정에서 "모든 사용자" 배포가 막혀 있으면 개인 구글 계정으로 만들어야 해요.
- 주소에 아무것도 없이 들어오면: config.js 의 Firebase 반(해바라기반) → 없으면 그 크롬북에서 마지막으로 연 시트 반 → 없으면 안내 화면. `?demo` 는 체험 모드.

## 체크리스트와 연결하기 (처음 한 번)

`js/config.js`를 열고 체크리스트 `app.js` 맨 위에 있는 내용을 그대로 옮겨 적어요.

```js
window.GG_CONFIG = {
  FIREBASE: { apiKey: "...", authDomain: "...", projectId: "...", ... }, // firebase.initializeApp( ) 괄호 안
  STUDENTS: [{ id: 1, name: "..." }, ...],                               // var STUDENTS = [ ... ]
  TEACHER_PASSWORD: '...',                                                // 체크리스트 관리자 비밀번호
  LEAGUE_NAME: '해바라기 리그',
  SEASON: 1
};
```

비워 두면 **체험 모드**(예시 선수 16명, 비밀번호 모두 `0000`, 이 브라우저에만 저장)로 열려요.

### Firestore 규칙

공기 리그는 같은 Firebase 프로젝트에 컬렉션 3개를 새로 씁니다: `gonggi_players`, `gonggi_matches`, `gonggi_settings`.
비밀번호는 체크리스트의 `studentPins`를 그대로 읽어요.
Firebase 콘솔 → Firestore → 규칙에서 컬렉션별로 막아 두셨다면 아래를 추가해 주세요. (모두 허용으로 되어 있으면 손댈 필요 없어요)

```
match /gonggi_players/{id}  { allow read, write: if true; }
match /gonggi_matches/{id}  { allow read, write: if true; }
match /gonggi_settings/{id} { allow read, write: if true; }
```

## 올리기와 링크 나눠주기

GitHub 저장소 Settings → Pages → Source: Deploy from a branch → 브랜치 선택, 폴더 `/ (root)` → Save.
몇 분 뒤 `https://kingseoho.github.io/5-3gonggi/` 주소가 생겨요. 선생님 메뉴의 **링크 나눠주기**에서 주소 복사와 QR 코드를 쓸 수 있어요.
`dist/gonggi-legends.html` 파일 하나로도 열 수 있어요(`npm run build`로 다시 만듦).

## 티어와 LP (피라미드)

| 티어 | LP | 단계 | 비슷한 상대에게 이기면 / 지면 |
| --- | --- | --- | --- |
| 아이언 | 0–199 | IV→I | +40 / −13 |
| 브론즈 | 200–399 | IV→I | +35 / −18 |
| 실버 | 400–599 | IV→I | +30 / −21 |
| 골드 | 600–799 | IV→I | +25 / −25 |
| 플래티넘 | 800–999 | IV→I | +21 / −28 |
| 에메랄드 | 1000–1199 | IV→I | +18 / −30 |
| 다이아몬드 | 1200–1399 | IV→I | +15 / −33 |
| 마스터 | 1400+ | 없음 | +13 / −35 |
| 그랜드마스터 | 1700+ | 없음 | +11 / −38 |
| 챌린저 | 2000+ | 없음 | +10 / −40 |

(기준 LP 25일 때. 선생님 메뉴에서 기준 LP를 바꾸면 전체가 같은 비율로 바뀌어요.)

- 낮은 티어는 금방 오르고, 위로 갈수록 오르기 어려워요. 실력이 반반인 아이는 골드 근처에서 멈추고, 그 위는 확실히 잘해야 올라가요.
- 티어 차이가 나면 Elo 공식으로 달라져요. 낮은 티어가 높은 티어를 이기면 크게 얻고, 높은 쪽은 크게 잃어요.
- 연승 보너스: 3연승 +3, 4연승 +5, 5연승부터 +8. 연패 보호: 3연패부터 잃는 LP 절반. LP는 0 아래로 안 내려가요.
- 점수는 **경기 기록을 처음부터 다시 계산**해서 나와요. 그래서 선생님이 기록 화면에서 경기를 고치거나 지우면 모든 LP가 저절로 맞춰져요.

## 개발

```
npm test        # 점수·티어·추천 계산, 저장소(가짜 Firestore), Apps Script(가짜 시트) 테스트
npm run build   # dist/gonggi-legends.html
```

- `js/config.js` 연동 설정
- `js/logic.js` 티어·LP·추천·대진표 계산
- `js/store.js` 저장소 (Firestore / 구글 시트 / 체험용 localStorage)
- `apps-script/Code.gs` 다른 선생님 반의 서버 (구글 시트에 붙이는 Apps Script)
- `js/avatar.js` 캐릭터 옷장과 그리기
- `js/app.js` 화면
- `css/style.css` 디자인
