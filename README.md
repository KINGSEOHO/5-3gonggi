# 공기 블록스 (GONGGI BLOX)

우리 반 공기놀이 리그 앱이에요. 친구와 공기 대결을 하고, 이기면 점수가 올라 티어가 올라갑니다.
리그 오브 레전드 티어 방식과 로블록스 앱 느낌의 화면을 썼어요.

## 바로 쓰기

- **파일 하나로 쓰기:** `dist/gonggi-blox.html`을 내려받아 교실 컴퓨터에서 더블클릭하면 크롬/엣지에서 열려요. 인터넷이 없어도 됩니다(글꼴만 기본 글꼴로 보여요).
- **폴더째 쓰기:** `index.html`을 열어도 똑같이 동작해요. GitHub Pages로 올리면 주소로도 열 수 있어요.

처음 열면 예시 반(14명)이 보여요. **예시 지우고 시작하기** → **친구 관리**에서 이름을 한 줄에 한 명씩 붙여넣으면 됩니다.

## 기능

| 화면 | 하는 일 |
| --- | --- |
| 홈 | 1~3등 시상대, 친구 카드, 최근 대결, 티어 분포 |
| 대결 | 빨강 팀/파랑 팀 고르기 → 이기면/지면 점수와 예상 승률 미리 보기 → 이긴 친구 버튼 |
| 상대 추천 | 비슷한 실력 · 도전(조금 높은 친구) · 처음 붙는 친구 |
| 오늘의 대진표 | 점수가 비슷한 친구끼리 자동으로 짝짓기 (최근에 붙은 친구는 피함, 쉰 친구는 다음에 먼저) |
| 랭킹 | 순위, 티어, 점수, 전적, 승률, 연승/연패. 티어별로 걸러 보기 |
| 프로필 | 캐릭터 꾸미기(옷 색, 표정), 다음 단계까지 남은 점수, 최근 대결, 쉬는 중 표시 |
| 기록 | 모든 대결. 잘못 누르면 마지막 대결부터 취소 |
| 친구 관리 | 친구 등록, 점수 규칙 바꾸기, 백업/불러오기, 새 학기 초기화 |

## 티어와 점수

- 티어: 아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아몬드 → 마스터 → 그랜드마스터 → 챌린저
- 다이아몬드까지는 티어마다 IV → III → II → I 네 단계(단계마다 50점, 티어마다 200점). 마스터 1400점, 그랜드마스터 1700점, 챌린저 2000점부터.
- 실력이 같으면 이기면 **+25**, 지면 **−15** (친구 관리에서 바꿀 수 있어요).
- 점수 차이가 클수록 **낮은 쪽이 이기면 더 많이**(최대 +50) 얻고, 높은 쪽은 더 많이 잃어요. 높은 쪽이 이기면 조금만(최소 +5) 올라요. 엘로(Elo) 공식으로 계산합니다.
- 3연승부터 연승 보너스(+2, +4 … 최대 +10). 점수는 0점 아래로 내려가지 않아요.

## 저장

기록은 그 컴퓨터 브라우저(localStorage)에 저장돼요. 다른 컴퓨터로 옮기거나 혹시를 대비해 **친구 관리 → 백업**을 가끔 해 두세요.

## 개발

```
npm test        # 점수/티어/추천 계산 테스트
npm run build   # dist/gonggi-blox.html 다시 만들기
```

- `js/logic.js` 티어, 점수, 상대 추천, 대진표 계산 (화면과 분리)
- `js/app.js` 화면과 동작
- `css/style.css` 디자인
